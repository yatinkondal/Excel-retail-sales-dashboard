# Retail Sales & Delivery Performance Dashboard | Excel

## Project Overview

This project focuses on analyzing retail sales and delivery performance using Microsoft Excel. The dashboard provides insights into revenue, regional performance, order status, and delivery trends.

## Business Problem

The objective is to understand sales performance, identify regional patterns, and evaluate delivery efficiency using a structured retail dataset.

## Tools & Technologies

* Microsoft Excel
* XLOOKUP
* Pivot Tables
* Pivot Charts
* Slicers
* KPI Cards
* Data Cleaning

## Dataset

* 100 retail transaction records
* Customer information
* Sales and order details
* Regional and delivery information

## Project Objectives

* Analyze total sales and revenue.
* Compare sales performance across regions.
* Identify product categories contributing to revenue.
* Examine order cancellations and delivery timelines.
* Present key findings through an interactive dashboard.

## Key Insights

* Electronics generated the highest revenue of ₹15,209.
* The North region recorded a cancellation rate of 40%.
* 11 orders, representing 11% of the dataset, were delivered within 2 days.

## Recommendations

* Investigate the reasons behind the high cancellation rate in the North region.
* Monitor delivery timelines to improve customer experience.
* Focus on high-performing product categories while evaluating regional sales opportunities.

The project demonstrates how Microsoft Excel can be used to convert raw retail data into meaningful business insights and support data-driven decision-making.
